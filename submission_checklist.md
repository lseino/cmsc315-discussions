# Grading Checklist Mapped to TODO Blocks

Use this checklist before submitting your weekly discussion.

## Code Modification Checklist

- [x] I did **not** submit the starter unchanged.
- [x] I completed every TODO block in the starter file.
- [x] I added additional test cases beyond the starter examples.
- [x] I improved the print statements so the output was easy to understand.
- [x] I added comments explaining important logic.

## Edge Case Checklist

- [x] I tested at least one edge case required by the starter.
- [x] I explained what happened in the output or README.
- [x] I handled empty structures, missing values, invalid input, or a comparable special case.

## Concept Understanding Checklist

- [x] My code demonstrated the required operations for the week.
- [x] My README explained how the structure or algorithm worked.
- [x] My README included at least one real-world use case or interpretation.

## Customization Checklist

- [x] I added my own example or scenario beyond the starter.
- [x] My code showed that I understood the topic rather than only running the file.

## GitHub Checklist

- [x] My weekly folder contains the Python file.
- [x] My weekly folder contains an updated README.
- [ ] I committed and pushed the files to my GitHub repository.
- [ ] I confirmed that the repository link opens for the intended audience.

## Discussion Checklist

- [ ] I explained my design approach in the initial discussion-board post.
- [ ] I posted my GitHub repository link in the discussion board.
- [ ] I responded to at least **two classmates**.
- [ ] Each peer reply was meaningful and referenced specific code or explanations.
